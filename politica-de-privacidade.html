2. Dados que Coletamos

O AVANCE coleta apenas os dados estritamente necessários para o funcionamento do serviço:

  • Dados de cadastro: endereço de e-mail e senha (armazenada de forma criptografada pelo Firebase Authentication).
  • Dados de perfil: nome de usuário informado voluntariamente pelo titular.
  • Dados de uso: hábitos, tarefas, registros financeiros, fichas de treino e atividades de estudo inseridos pelo próprio titular.
  • Dados de pagamento: informações necessárias para processamento da assinatura mensal. Os dados de cartão nunca são armazenados diretamente pelo AVANCE — o processamento é realizado por plataforma de pagamento terceirizada.
  • Dados técnicos: logs de autenticação gerados automaticamente pelo Firebase (Google LLC) para fins de segurança.
  • Dados de uso do aplicativo: por meio do Google Firebase Analytics, coletamos de forma agregada informações sobre como o aplicativo é utilizado — como seções acessadas, ações realizadas (por exemplo, criação de itens), tipo de dispositivo e navegador, e região aproximada estimada pelo endereço IP. Esses dados são usados apenas para entender o uso geral e melhorar o serviço, não para identificá-lo individualmente.

O AVANCE não coleta sua localização precisa (GPS), contatos, câmera, microfone ou dados sensíveis. A região aproximada mencionada acima é estimada pelo Google a partir do endereço IP, exclusivamente para fins estatísticos de uso.

3. Finalidade do Tratamento

Os dados coletados são utilizados exclusivamente para:

  • Autenticar o usuário e garantir a segurança da conta;
  • Armazenar e sincronizar os dados inseridos pelo próprio titular entre dispositivos;
  • Processar e gerenciar a assinatura mensal;
  • Enviar comunicações essenciais relacionadas à conta (confirmação de e-mail, recuperação de senha, avisos de cobrança).

O AVANCE não utiliza seus dados para publicidade, não vende dados a terceiros e não realiza perfilamento para fins comerciais.

4. Base Legal

O tratamento dos dados pessoais pelo AVANCE fundamenta-se nas seguintes bases legais previstas na LGPD:

  • Execução de contrato (art. 7º, V) — para prestação do serviço de assinatura;
  • Legítimo interesse (art. 7º, IX) — para fins de segurança, prevenção a fraudes e análise agregada de uso para melhoria do serviço;
  • Consentimento (art. 7º, I) — para comunicações opcionais.

5. Armazenamento e Segurança

Seus dados são armazenados no Google Firebase / Firestore, na região southamerica-east1 (São Paulo, Brasil), sob os padrões de segurança do Google Cloud Platform.

Medidas de segurança adotadas:

  • Criptografia em trânsito (TLS/HTTPS) e em repouso;
  • Regras de acesso que garantem que cada usuário acessa apenas os próprios dados;
  • Autenticação obrigatória para qualquer operação de leitura ou escrita;
  • Verificação de e-mail para ativação da conta.

6. Compartilhamento de Dados

Os dados pessoais dos titulares são compartilhados apenas com os seguintes fornecedores essenciais para a operação do serviço:

  • Google LLC (Firebase) — autenticação, armazenamento de dados e análise de uso (Firebase Analytics);
  • Processadora de pagamento — para cobrança da assinatura mensal.

Todos os fornecedores operam sob políticas de privacidade próprias e em conformidade com a legislação aplicável. O AVANCE não compartilha dados com terceiros para fins publicitários ou comerciais.

7. Retenção de Dados

Os dados pessoais são mantidos enquanto a conta do titular estiver ativa. Após o cancelamento da assinatura e exclusão da conta:

  • Os dados de uso são excluídos em até 30 dias;
  • Registros de transações financeiras podem ser mantidos por até 5 anos para cumprimento de obrigações legais e fiscais.

8. Direitos do Titular

Nos termos da LGPD, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados;
  • Acessar seus dados;
  • Corrigir dados incompletos, inexatos ou desatualizados;
  • Solicitar a anonimização, bloqueio ou eliminação dos seus dados;
  • Portabilidade dos dados a outro fornecedor;
  • Revogar o consentimento a qualquer momento;
  • Cancelar sua conta diretamente nas configurações do aplicativo.

Para exercer qualquer direito, entre em contato pelo e-mail: guiilherwmeti@gmail.com. Responderemos em até 15 dias úteis.

9. Cookies, Identificadores e Análise de Uso

O AVANCE não utiliza cookies ou pixels para publicidade e não realiza monitoramento comportamental para fins comerciais.

Utilizamos o Google Firebase Analytics para entender de forma agregada como o aplicativo é usado (por exemplo, quais seções são mais acessadas e quantos usuários concluem determinadas ações), com o único objetivo de melhorar o serviço. Para isso, o Google pode utilizar identificadores do dispositivo e tecnologias semelhantes a cookies. Esses dados são tratados de forma estatística e não são usados para identificá-lo individualmente nem para direcionar anúncios. O tratamento realizado pelo Google segue a política de privacidade da própria empresa, disponível em policies.google.com/privacy.

10. Idade Mínima

O AVANCE é destinado a usuários com 16 anos ou mais. Não coletamos intencionalmente dados de menores de 16 anos. Caso identifiquemos que uma conta foi criada por menor de 16 anos sem autorização dos responsáveis, a conta será encerrada.

11. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas por e-mail ou notificação no aplicativo com antecedência mínima de 10 dias. O uso continuado do serviço após a vigência das alterações implica a aceitação da nova versão.
